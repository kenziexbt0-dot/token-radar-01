How the implied value is built

One formula scores every protocol. Nothing is special-cased by name.

base      = TVL × 0.30
size      = clamp((100M / TVL) ^ 0.12, 0.55, 1.45)
growth    = clamp(7d change, -80%, +200%); up × 0.55, down × 0.85
maturity  = 0.55 + min(age, 1460d) / 1460 × 0.45   (unknown age: 180d)
breadth   = 1 + 0.04 × min(chains - 1, 4)
implied   = round(base × size × growth × maturity × breadth)
  • Size: a small protocol's token would price off a higher multiple than a giant's — fully diluted value compresses against TVL as a protocol matures.
  • Growth: a falling TVL hurts more than a rising one helps.
  • Maturity: four years running with no token earns the full maturity factor; a young protocol earns less.
  • Breadth: each extra chain adds reach, up to four.

The snapshot is a sealed record from DefiLlama's public API, fetched once. It is not proof: a protocol on this board records no token, which is not the same as having none. Implied value is this radar's own claim about what a token would be worth if the protocol's record stayed as it is — not a prediction of whether or when a token is issued, and not financial advice.
